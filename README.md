Requisitos técnicos e implementación

1. Estructura semántica y accesibilidad
* Etiquetado: Uso correcto de las diferentes etiquetas de HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`) para ordenar el contenido.
* Accesibilidad (ARIA): Inclusión de atributos ARIA para garantizar la navegabilidad con lectores de pantalla.
* Formularios accesibles: Todos los campos de entrada (`<input>`, `<textarea>`) están vinculados correctamente con sus respectivas etiquetas (`<label>`).

2. Maquetación con Flexbox y CSS Grid
* Flexbox: Implementado en la cabecera (`.header`), la alineación de la sección principal (`.hero-container`), los contenedores de botones y la estructura del pie de página (`.footer`).
* CSS Grid: Utilizado en la sección de habilidades (`.skills-grid`) para lograr una distribución adaptativa y responsiva (`repeat(auto-fit, ...)`).

3. Animaciones e interactividad
* Entrada animada:*Animación `slideUpFade` al cargar.
* Efecto visual: Animación en bucle (`pulseGold`) que rodea la fotografía de perfil.
* Microinteracciones: Efectos `:hover` y transiciones suaves en enlaces, botones y tarjetas de habilidades.
